# Zellij Cheatsheet

An interactive, searchable Zellij cheatsheet: keybindings, modes, layouts, and CLI commands on one page, with live search and click-for-detail descriptions.

**Live site: [zellijcheatsheet.dev](https://zellijcheatsheet.dev)**

## Features

- Live search across every keybinding and command, with match highlighting
- Click any item for a description and example
- Click-to-copy on commands
- Light and dark mode
- No logins, no ads

## Contributing

Corrections and additions are very welcome. Accuracy is the priority here, so **please cite a source** (the official Zellij documentation at zellij.dev, the `zellij` man pages, or the Zellij source / default keybindings) for any change. See [CONTRIBUTING.md](CONTRIBUTING.md) for the quick guide.

If this cheatsheet saves you a trip to the docs, a ⭐ helps others find it. Corrections and PRs are always welcome.
